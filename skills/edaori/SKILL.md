# Edaori（枝折）— 会話の分岐ナビ

山道で枝を折って帰り道の目印にしたように、会話の分岐点に目印を残し、
あとで迷わず戻れるようにする。記録の正本は `branches.json`。AIの記憶は当てにしない。

## コマンドの実行方法

このSKILL.mdと同じフォルダにある `scripts/edaori.py` を使う（標準ライブラリのみ、Python 3.9+）。

```
python <このスキルのフォルダ>/scripts/edaori.py <コマンド> ...
```

- 例: `python ~/.claude/skills/edaori/scripts/edaori.py status`
- `python` が無い環境では `python3`。
- 毎回 `--tool <claude|copilot|cursor>` を付けて、どのAIで記録したかを残す。
- ノードIDは `n_004` でも `4` でもよい。わからなければ `tree` で確認する。

## いつ何を呼ぶか

| 状況 | コマンド |
| --- | --- |
| テーマが無い／新しい話題を始める | `init "テーマ名"`（gitリポジトリ内なら自動で `.edaori/` に保存） |
| 選択肢・並行検討・脱線が出た | `fork "分岐点の問い" --options "A" "B" ... --snapshot-file <file> [--pick N]` |
| 今の枝で進捗があった | `note "1行メモ"` |
| 今の枝を途中で止める | `park "止めた理由" --stopped-at "どこまでやった・次に何をする予定だった" --until "再開条件"` |
| 今の枝をやり切った | `done "結論1行"` |
| 選択肢を捨てる | `reject "理由" --id <id>` |
| 分岐点・別の枝に戻る | `resume <id>`（省略すると NEXT に戻る） |
| 次に何をやるか | `next` / 全体は `status` / `tree` |
| 保留の再開条件が満たされた | `ready <id>` |
| チャットを締める | `wrap-up`（下の手順） |

判断の基準: **「あとで戻りたくなるか」** で枝にするか決める。小さなことは `note` で済ませ、枝を細かくしすぎない。

## fork の手順（最重要）

分岐した瞬間が、会話の文脈を一番正確に持っている。その場でスナップショットを書く。

1. 次の形式で 500〜800字のスナップショットを書き、一時ファイルに保存する
   （改行を含むので `--snapshot` より `--snapshot-file` が安全。`-` で標準入力も可）。

   ```
   目的: この会話で最終的に達成したいこと
   前提: 制約・条件・ユーザーの状況
   決定済み: ここまでに決まったこと
   選択肢: 各選択肢と、それぞれの論点・懸念
   未解決の問い: まだ答えが出ていないこと
   原文の抜粋: 判断の決め手になった発言を2〜3個そのまま引用
   ```

2. `fork` を実行する。すぐ1つを進めるなら `--pick 番号`。
3. 実行結果（分岐と選択肢の一覧）をユーザーに短く見せる。

## resume の手順

1. `resume <id>` を実行し、出力された「復帰パック」を読む
   （①分岐時点の記憶 ②この枝の途中経過と止めた位置 ③その後ほかの枝で分かったこと）。
2. 再開前に **目的・前提・次の一手を3行で復唱** し、ユーザーの確認を取る。
3. ③の新しい結論と矛盾する古い前提があれば、復唱の中で指摘する。

Claude Code の `/rewind` など、元の会話そのものに戻れる機能がある場合は併用してよい。その場合も ③ だけは補う。

## done / park の後

コマンドは自動で NEXT を表示する。ユーザーに「次は ○○ に戻りますか？」と1行で提案する。
勝手に次の枝へ進まない。

## wrap-up（チャットを締める）の手順

1. `status` と `tree` で記録を確認する。
2. 会話全体を振り返り、**記録漏れ候補**（分岐・決定・保留・完了したのに記録していないもの）を箇条書きで提示する。
3. ユーザーが承認したものだけ `fork` / `done` / `park` / `reject` で追加する。
4. `wrap-up` を実行し、出力された実施レポートをそのまま見せる。
   ファイルに残すなら `wrap-up --out <path>`。次のチャットの冒頭に貼れば引き継ぎになる。

## ユーザーへの見せ方

- 記録したら、何を記録したかを1〜2行で伝える（長いツリーを毎回貼らない）。
- 「今どこ？」には `status`、「全体を見せて」には `tree`、画面で見たいと言われたら `view`（ブラウザでナビ画面が開く）。
- 記号: ○未着手 ▶進行中 ‖保留 ✓完了 ×却下 ◆分岐点。

## 保存先

- gitリポジトリ内: `<repo>/.edaori/themes/<テーマ>/branches.json`（`.git/info/exclude` に自動登録。共有しない）
- それ以外: `~/.edaori/themes/<テーマ>/branches.json`（`EDAORI_HOME` で変更可）
- 全テーマの台帳: `~/.edaori/index.json`。`themes` で一覧、`use <slug>` で切替。
